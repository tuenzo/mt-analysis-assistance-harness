# Keemart 周期性促销评估 Demo 报告

## 一句话结论

演示样本显示，活动期 GMV 和购买 UV 有明显抬升，但真实促销增量需要剔除发薪周期和曝光增长的自然贡献。

## 关键发现

1. Drinks 和 Baby 类目在活动期同时出现曝光提升和 GMV 提升，是优先复盘对象。
2. Rice/Oil 在发薪窗口表现较强，不能直接把全部增量归因于促销。
3. Beauty 的响应较温和，更适合控制折扣并观察复购。

## 策略建议

| category | action | rationale |
| --- | --- | --- |
| drinks | 加码曝光 | 高曝光下仍保持较高 buy_uv |
| baby | 控折扣优化 | GMV 高但让利强度也高 |
| rice_oil | 发薪日前置 | 需求受 payday window 影响明显 |
| beauty | 小流量测试 | 当前 uplift 信号较弱 |

## 结论边界

这是演示数据，用于展示工作流和报告形态；生产决策需要完整样本、利润口径和实验验证。
