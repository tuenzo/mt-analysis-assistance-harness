# Keemart 系统展示点击说明

## 准备

打开真实前端路由：

```text
http://127.0.0.1:3010/projects/keemart-saudi-promo-review/agent
```

如果页面曾经被演示过，先点击右上角“重置对话”。

## 含记忆模块的点击顺序

### 1. 承接进入平台，停留 10 秒

页面停留在 Agent 分析中心顶部，口头说明：

- 当前项目是 Keemart 沙特月末促销复盘。
- 右上角显示本项目接入的美团大模型。
- 项目管理、数据接入、报告和记忆一笔带过，重点展示 Agent 分析和结果看板如何协同。

### 2. Agent 一次对话：活动是否有效，停留 45 秒

点击建议输入卡片：

```text
活动是否有效
```

等待系统返回到最后一条 Agent 回答。讲解重点：

- Agent 先规划分析任务，再按事件流调用工具。
- 说清楚功能链路：数据校验、品类日面板、PSM-DID 评估。
- 说明系统能控制月末发薪等自然周期，判断活动是否存在可归因增量。

### 3. 切换结果看板并点击明细，停留 55 秒

点击左侧导航：

```text
结果看板
```

进入：

```text
http://127.0.0.1:3010/projects/keemart-saudi-promo-review/dashboard
```

看板讲解顺序：

1. 顶部 KPI：说明这里汇总总体效果和增量拆解。
2. Pareto、瀑布图、趋势图：说明分别对应品类集中度、增量来源和活动期走势。
3. 点击顶部 `GMV 净增量` 卡片，打开右侧明细抽屉。
4. 在抽屉里说明每日实际 GMV、自然基线和净增量可以对应查看，因此看板既给总览，也支持下钻核验。
5. 关闭抽屉，指向四象限气泡图和右侧策略卡片：讲优先加码、稳定维持、控制折扣、避免打扰四类运营动作。

### 4. 回到 Agent 追问解释，停留 30 秒

点击左侧导航：

```text
Agent 分析
```

点击建议输入卡片，或在输入框发送：

```text
解释曝光贡献
```

讲解重点：

- 追问内容是：为什么这里把曝光贡献作为主引擎。
- Agent 会把顶部净增量、LocalGap 分解和 Uplift 结果串起来解释。
- 这一步体现看板不是静态报表，业务人员可以带着疑问回到 Agent 继续核验口径和策略逻辑。

### 5. 切到记忆模块，停留 35 秒

点击左侧导航：

```text
记忆
```

讲解顺序：

1. 顶部指标：说明这里展示待审核候选、已写入项目记忆和下一轮复用规则。
2. 候选记忆：指向“活动效果识别口径”“曝光与折扣的资源角色”“下一轮品类分层策略”“边际收益风险边界”。
3. 点击任意一条待审核候选的 `通过写入`，推荐点击：

```text
曝光与折扣的资源角色
```

4. 指向右侧“已存储的项目记忆”，说明候选内容审核后进入项目级上下文。
5. 指向“下一轮复用方式”，说明下一次同类活动启动时，Agent 会先读取项目记忆，但用户级同步和敏感信息沉淀仍需受控。

## 注意事项

- 按真实使用场景讲，不主动解释演示资产属性。
- 不要讲页面右侧为“讲稿”，讲稿不进入演示 UI。
- 指标数字作为页面证据出现，口头重点放在分析能力、口径解释和可执行策略。
- 记忆模块重点讲“候选生成、人工审核、项目级写入、下一轮复用”，不要展开成权限系统细节。
- 重点表达：美团开发的大模型负责推理、规划与调度，受控分析工具网关负责确定性执行，结果看板负责把复杂模型结果翻译成运营决策。
